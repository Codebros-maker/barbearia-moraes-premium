## Conceito visual
Impacto urbano e linguagem direta: preto profundo, laranja vibrante, tipografia brutalista e imagens em preto e branco.

## Funcionalidades
Lista de serviços clicável, galeria de referências e formulário de solicitação de data/horário que prepara mensagem para WhatsApp (não confirma agenda).

## Antes de fechar contrato

- Este projeto é uma **demonstração não oficial**, não aprovado pelo estabelecimento. O aviso no topo e o rodapé devem permanecer até o proprietário autorizar a publicação como página oficial.
- Categorias, serviços, horários e disponibilidade precisam de confirmação antes da publicação definitiva. Nenhum preço, promoção, avaliação ou depoimento foi inventado.
- Os botões montam mensagens no WhatsApp. **Não existe sistema de pagamento, agenda online integrada ou confirmação automática.**
- As imagens e fontes externas exigem internet; os estilos têm fallback sem dependências JS.

## Publicar na Vercel
1. Extraia o ZIP individual; os arquivos `index.html`, `style.css`, `script.js`, `vercel.json` precisam estar na **raiz** do projeto.
2. Suba a pasta para um repositório no GitHub e importe na Vercel.
3. Framework: `Other`; Build command: vazio; Output directory: vazio. Deploy.
4. Para usar o ZIP geral, escolha no GitHub uma pasta por projeto ou configure `Root Directory` com a pasta desejada.
